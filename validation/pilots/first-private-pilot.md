# First private-project Guide usability pilot — preparation

**Status:** Prepared in a private project branch; independent participants and usability results **not yet available**.  
**Scope:** The Guide's ability to help a developer read existing source/docs and choose the smallest useful explanation.

To respect the target project's confidentiality, participant tasks, pinned source baseline, expected-source notes and session records live **only in the private target repository**. This public page intentionally does **not** link to private code, disclose implementation details, or copy project-specific research artifacts.

## What will be tested

1. **Reader navigation:** Can a newcomer locate an existing interface's real responsibility boundary using the repository's own entry points?
2. **Guide transfer:** Does reading [the Guide](../../guide/README.md) help a participant navigate a *different* code boundary rather than merely repeat a worked example?
3. **Author autonomy:** When someone proposes another long document, can the coding contributor choose a small existing-doc fix, better code, a useful example or **no extra writing**?
4. **Reader outcome:** Can a second person perform or explain the task after the change, without a new documentation bureaucracy?

Participants will not be forced to use the optional [advisory tool](../../tools/jitdw_advisor.py). A negative result or “no change needed” is a valid outcome.

## Evidence standards

The private pilot must distinguish verified source facts, participant behavior, research interpretation and untested claims. Timing comparisons require suitable participants or counterbalanced tasks; reading a public Guide example must not expose the private task's answer. No usability improvement, maintenance-cost reduction or score is claimed yet.

**Public/private boundary:** This is a public Guide project; private source snapshots, identifiers, answer keys and internal project histories should not be placed here merely to make a study reproducible. Publish aggregated observations only after explicit review and permission.
