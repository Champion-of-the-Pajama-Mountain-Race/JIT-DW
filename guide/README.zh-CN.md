# JIT-DW 中文导读

**JIT-DW 首先是给开发者的文档实践 Guide，不是审核规范。**

**想先完整体验一次中文方法？从 [十分钟实践指南](quickstart.zh-CN.md) 开始。** 这份中文文档能够独立阅读；下面的目录则导航至更详细的英文正文。

它想帮助真正写代码的人决定：谁需要什么解释、在哪里写最自然、写多少才够，以及怎样让解释随开发演进。指南不会强制要求每个模块都写 README、每次提交都改文档，或安装我们的检查器。

## 五句话说明我们的立场

1. **代码的作者有判断权。** JIT-DW 提供方法、案例与取舍，不通过文档流程压制开发。
2. **文档是为读者解决问题。** 不是为了凑文件数量、填写模板和拿到 CI 绿灯。
3. **先考虑更好的代码和接口。** 有时正确的做法是改名字、改 API、写测试或删掉多余注释，而不是增加新文档。
4. **在需要的时候才引入额外机制。** 一个 README 足够，就不需要文档站点、ADR 管理和检查器。
5. **研究服务于指南，工具只是配件。** 我们保留 Codex、AstrBot、Chromium、Rust、Django 等项目的实证材料，但把它们转化为开发者能用的思路。

如果只读一个章节，建议先看 [何时需要文档](01-when.md)。不安装任何工具，也可以实践 JIT-DW。
